<h1 align="left">Hey 👋 What's up?</h1>

<p align="left">I'm William, a backend engineer who builds event-driven backend systems for marketplaces, social platforms, and mobility apps. I've led backend teams, architected services from scratch, and shipped production systems handling real-time messaging, payments, and async processing at scale. Off the clock, I'm usually binge-watching anime, catching up on sleep, or recovering from the latest coding marathon.</p>

<p align="left">Fun fact: I once wiped an entire production database while "quickly fixing" a query bug. Lesson learned—the hard way. Backups are now my best friends! 😅</p>

<h2 align="left">About me</h2>

<p align="left">
🚀 2+ years of hands-on production experience building distributed backend systems<br>
🧠 Comfortable owning backend architecture end-to-end — API design, distributed messaging (RabbitMQ, BullMQ), caching (Redis), and real-time communication (Socket.IO)<br>
👥 Track record leading and mentoring backend engineers on live production codebases<br>
🌍 Open to remote roles, relocation, and visa sponsorship<br>

</p>

<h2 align="left">What I've been building</h2>

<p align="left">
🔹 <b>Findme</b> — Led a small backend team on a social media platform's core services and notification system, designing microservices with RabbitMQ for service-to-service messaging.<br>
🔹 <b>AppFur</b> — Built and maintained backend services across three production apps (Blumdate, Mecfur, Victhon) spanning social, mobility, and service-marketplace domains, with RabbitMQ, Socket.IO, and JWT/RBAC auth.<br>
🔹 <b>Sylvester Analaba</b> — Architected a multi-vendor marketplace backend from the ground up (500+ users, 10+ vendors), leading a team of 10+ developers.<br>
🔹 <b>Roam Haven</b> — Co-founded and built an Airbnb-style booking platform with Stripe payments and host–guest messaging.
</p>
